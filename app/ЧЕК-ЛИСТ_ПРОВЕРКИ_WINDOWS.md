# ПРОВЕРКА DASTARHAN НА ТВОЁМ НОУТЕ (PowerShell) — все 6 модулей

_Модули: 1) касса POS · 2) бэк-офис · 3) KDS кухня · 4) курьер · 5) QR-меню гостя · 6) API-логика (деньги, склад, фискал…). Всё проверяется в 2 шага без базы и без Docker; полноценный запуск с базой — шаг 3._

## Подготовка (один раз, 5 минут)
1. Установи Node.js 22 LTS: https://nodejs.org → «Windows Installer», дальше-дальше.
2. Распакуй `dastarhan_ВСЁ_ДЛЯ_ПРОВЕРКИ.zip` в `C:\dastarhan` (правой кнопкой → Извлечь всё).
3. Открой PowerShell: Win+X → «Терминал».

## ШАГ 1 — Логика всех 6 модулей: 593 теста одной командой
```powershell
cd C:\dastarhan\dastarhan\selftest
node -v          # должно показать v22.x
npm install      # ~30 секунд, тянет react + esbuild
node check-all.mjs
```
**Ожидаемый результат** (последняя строка):
```
══════ ИТОГО: 593 прошло, 0 упало ══════
ВСЁ ЗЕЛЁНОЕ ✅
```
Что именно проверилось по модулям:
- test..test10 — API-логика: заказы, деньги/сдача/возвраты, фискальная очередь, склад (средневзвешенная, инвентаризация), P&L/налог КЗ, бонусы/долги, доставка/рейсы, ИИ-матчинг, вертикали (EAN-13, повременка), платформа (grace, proration)
- test11, test16 — касса: view-модели + живой рендер PIN/зал/заказ/оплата
- test12, test17, test18, test20 — бэк-офис: навигация, техкарта с фудкостом, склад-экраны, 6 отчётов, шахматка броней
- test19 — KDS кухни · test22 — курьер · test21 — QR-меню гостя
- test13 — интеграции КЗ (Telegram-бот, Kaspi QR, re:Kassa, Wolt) · test14 — казахский словарь · test15 — печать ESC/POS байтами

start превью_КАССА.html      # тёмная касса: PIN, зал, заказ, оплата, KDS

## Если что-то не так
- `node не является командой` → Node не установлен или PowerShell не перезапущен после установки.
- Красные тесты → пришли мне последние 30 строк вывода — разберу.
- Превью без стилей → открой файл из распакованной папки, не из архива.
